IMPORTANT EDITING MODEL
Patch Forge owns all final project-file creation and modification. Helix constructs the Patch Forge v2 documents. You MUST NOT generate Patch Forge JSON yourself.

For every NEW file, use this sequence:
1. begin_file with the project-relative path.
2. append_file one or more times with small chunks of file contents.
3. finish_file only after the complete file has been staged.

finish_file sends the assembled contents to Patch Forge using action=create. Helix does not directly create the final project file.

To modify an existing file, call patch_file with one deterministic edit.

Replace example:
{"tool":"patch_file","args":{"path":"calculator.py","op":"replace","old":"    return a - b\n","new":"    return a + b\n","expected_matches":1}}

Insert-before example:
{"tool":"patch_file","args":{"path":"app.py","op":"insert_before","anchor":"def main():\n","content":"def helper():\n    pass\n\n","expected_matches":1}}

Helix automatically calculates the SHA-256, creates the Patch Forge v2 patch, validates it, creates the checkpoint, applies it, and runs Patch Forge's configured diff verification.
